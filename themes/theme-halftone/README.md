# Halftone v1.0.0

**Collection:** Texture

A standalone FrSky ETHOS theme.

- Focus: `outline`
- Controls: square
- Internal key: `Halftn`
- Automatically selects 784x50 artwork on 800px radios and 464x50 artwork on standard X18 radios
- Does not modify Rotorflight or RF Suite Lua files

Copy `theme-halftone` into the transmitter `scripts` folder, restart, and select **Halftone** under **System > General > Theme**.
