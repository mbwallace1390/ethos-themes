# Night Current v1.0.1

## Preview before installing

After extracting the ZIP on your computer, open [preview.png](preview.png) to see this theme's colors and artwork. The control layout is illustrative, not a firmware screenshot.

ETHOS Suite installs only the runtime files and leaves this preview on your computer. For manual installation, you can omit `preview.png`.

Requires ETHOS 26.1.0 or newer; API checked against 26.1.2. Radio validation is still required.

Install the ZIP with ETHOS Suite's local ZIP installer. For manual ZIP installation, create `scripts/theme-night-current/` on the transmitter and extract the ZIP contents into that folder.

**Family:** New Designs

A standalone FrSky ETHOS theme.

- Focus: `outline`
- Controls: rounded
- Internal key: `NtCurr`
- Automatically selects 784x50 artwork on 800px radios and 464x50 artwork on standard X18 radios
- Deep navy and pearl with flowing teal currents around the centered wordmark.
- Static artwork with no recurring Lua drawing or telemetry work
- Palette-matched ETHOS header logo with a transparent background
- Continuous toolbar styling with prominent artwork arranged around the lettering at both native widths

To install from repository sources, copy `theme-night-current` into the transmitter `scripts` folder, restart, and select **Night Current** under **System > General > Theme**.
