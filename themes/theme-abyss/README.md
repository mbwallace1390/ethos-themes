# Abyss v1.0.0

**Collection:** Elements

A standalone FrSky ETHOS theme.

- Focus: `outline`
- Controls: square
- Internal key: `Abyss`
- Automatically selects 784x50 artwork on 800px radios and 464x50 artwork on standard X18 radios
- Does not modify Rotorflight or RF Suite Lua files

Copy `theme-abyss` into the transmitter `scripts` folder, restart, and select **Abyss** under **System > General > Theme**.
