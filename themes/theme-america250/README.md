# America 250 v1.2.2

## Preview before installing

After extracting the ZIP on your computer, open [preview.png](preview.png) to see this theme's colors and artwork. The control layout is illustrative, not a firmware screenshot.

ETHOS Suite installs only the runtime files and leaves this preview on your computer. For manual installation, you can omit `preview.png`.

Requires ETHOS 26.1.0 or newer; API checked against 26.1.2. Radio validation is still required.

Install the ZIP with ETHOS Suite's local ZIP installer. For manual ZIP installation, create `scripts/theme-america250/` on the transmitter and extract the ZIP contents into that folder.

**Collection:** Commemorative

A standalone FrSky ETHOS theme.

- Focus: `outline`
- Controls: square
- Internal key: `USA250`
- Automatically selects 784x50 artwork on 800px radios and 464x50 artwork on standard X18 radios
- Original commemorative artwork, drawn natively for both display sizes
- Default ETHOS header logo replaced with a transparent bitmap to keep the inscription visible

To install from repository sources, copy `theme-america250` into the transmitter `scripts` folder, restart, and select **America 250** under **System > General > Theme**.
