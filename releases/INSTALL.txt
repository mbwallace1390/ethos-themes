ETHOS Themes - ETHOS 26.1.0 or newer

Download the latest ZIP for your theme from the main catalog.
To preview it first, extract the ZIP on your computer and open preview.png.
The image is an illustration using the theme's artwork and colors.

Suite: Lua Library > Install from local .zip, select the original theme ZIP.
The package manifest excludes preview.png, so Suite does not install it.
Restart the transmitter and select the theme under System > General > Theme.

Manual: create scripts/<theme-folder>/ and extract the ZIP contents there.
Example: scripts/theme-carbon/main.lua, with manifest and both toolbar PNGs
beside it. Do not extract loose files directly into scripts. You may omit
preview.png when copying a theme manually; it is for viewing on your computer.

When updating, remove the old main.luac from that theme folder so ETHOS
recompiles the new source. Keep the theme folder name and internal key.

The repository's complete source theme folders can also be copied into scripts.
Older folder-wrapped ZIPs are preserved for manual installation. Current ZIPs
have the manifest and main.lua at the archive root and work with Suite.
See ../ETHOS26.md for compatibility, rollback, sources, and validation limits.
