# Stormfront cloud source

`clouds-source.png` is an original static artwork source generated with the
built-in `image_gen` tool on September 30, 2026, after the user approved the
Stormfront concept. The saved source is a 2172x724 RGB PNG. Its SHA-256 is
`92c3d78d495614cdebe195f3659ba6b0f8e6714a17028b52aa76f05bb2167748`.

This file is a desktop build input. `generate_new_designs.py` takes independent
panoramic crops for the two radio sizes and adds the lightning at native size.
The packaged radio artwork contains no animation or recurring Lua drawing.
The ETHOS wordmark is supplied separately by the existing shared logo helper.

## Generation prompt

Generate ONE text-free source artwork PNG for the approved STORMFRONT FrSky ETHOS radio theme. This is an image asset, not a UI mockup. A panoramic, very wide band of layered storm clouds in cool dark slate and electric blue, polished realistic cloud texture with softly illuminated rounded cloud edges. Aim for 3072x1024 landscape panorama, three times wider than tall. Cloud material fills the entire image without borders, flat margins, cards, or captions. Rolling thunderclouds cluster toward the two outer thirds; the middle has softer, darker cloud detail, still continuous and textured, not a flat void. The main cloud formations sit across the middle horizontal third so a long narrow crop will remain recognizable as storm clouds. All clouds are compact, layered and billowy, not tall vertical towers. The overall palette is #111A24 navy slate shadows, #223344 steel blue, restrained #61BAFF electric-blue edges with small #B7DEFF ice-blue highlights. Atmospheric but clean and calm enough as a 50-pixel-tall toolbar texture. The two edges carry the brighter shapes and light; the central 20% has quiet continuous storm haze so ivory lettering can be overlaid separately. IMPORTANT: absolutely no text, no ETHOS wordmark, no logo, no lightning bolts, no sun, no moon, no horizon landscape, no interface controls, no objects. Lightning and the ETHOS logo will be added precisely later at native radio size. Keep texture across the whole middle, with no rectangular erased center or blank patch. Static image only.
